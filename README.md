# City Cart - React E-Commerce Application

## Run instructions:
1. Extract this zip folder.
2. Open terminal in the extracted folder.
3. Run `npm install` to install dependencies.
4. Run `npm dev` or `npm run dev` to start the development server.

## Features:
- Exact yellow navbar design (`CITY CART`, Search, Home, Categories, Login/User Profile, Cart badge).
- 20 pre-loaded diverse products with category and price tags.
- Sidebar filters by Price range and Categories with Reset Filters button.
- Google Login Simulation:
  - If logged in with admin email (`admin@citycart.com`), Admin Dashboard opens where products can be added or deleted.
  - If logged in with any other customer email, Customer profile / orders show up.
- Add to Cart functionality with Cart drawer/modal.
- PayPal Payment integration simulation for checkout.
